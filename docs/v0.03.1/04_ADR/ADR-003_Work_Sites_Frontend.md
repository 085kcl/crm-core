# ADR-003 — Work/Sites como frontend inicial

**Status:** Aceita

## Decisão

Usar ChatGPT Work/Sites para o MVP e iteração, tratando a interface como substituível.

## Consequências

Entrega rápida e integração com o fluxo de trabalho. O Git preserva o código e o Supabase preserva dados/regras; não armazenar dados críticos apenas no Site.
